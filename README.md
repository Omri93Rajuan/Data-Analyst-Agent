# Bitext Customer Service Data Analyst Agent

A command-line data analyst agent for the Bitext Customer Service dataset.

The agent answers questions about the dataset, including structured questions, open-ended summaries, and gracefully rejects out-of-scope questions.

## Features

- Structured dataset queries
- Open-ended category summaries
- Out-of-scope question routing
- Persistent session memory
- Follow-up query support
- FastMCP server exposing dataset tools
